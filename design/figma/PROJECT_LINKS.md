## How to Use

1. **For Design Review:** Share Figma links with stakeholders, leave comments
2. **For Development:** Engineers export assets (buttons, icons) from UI Kit
3. **For QA:** Developers compare built UI against High-Fi screens
4. **Prototype Testing:** Use Figma's interactive prototypes to test flows on device
